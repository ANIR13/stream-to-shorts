# Getting help

## 1. Read the guides

- **[User guide](docs/USER-GUIDE.md):** how to use the app, captions, styles, several videos, keyboard shortcuts and a **troubleshooting** section.
- **[Kali Linux guide (PDF)](docs/Kali-Linux-Guide.pdf):** install and run the app on Kali, Debian or Ubuntu.
- **In the app:** press **?** for keyboard shortcuts; when a task fails, **Tasks → Technical details** shows what went wrong.

## 2. Search existing issues

Someone may already have had the same problem: [search the issues](https://github.com/ANIR13/stream-to-shorts/issues?q=is%3Aissue), including closed ones.

## 3. Ask or report

- **Something doesn't work:** open a [bug report](https://github.com/ANIR13/stream-to-shorts/issues/new?template=bug_report.yml). Include your system (Windows / Linux), what you did, what you expected, and the error from **Tasks → Technical details**.
- **An idea or a missing feature:** open a [feature request](https://github.com/ANIR13/stream-to-shorts/issues/new?template=feature_request.yml).
- **A security problem:** don't open a public issue; follow the [security policy](SECURITY.md).

Please don't attach your recordings or rendered shorts to public issues; a screenshot or a short description is usually enough.

## Response times

Stream → Shorts is maintained by one person in their free time. Most issues get an answer within a few days; thanks for your patience.

If the app saves you time, you can [buy the maintainer a coffee](https://buymeacoffee.com/mastersrecipes). Contributions are welcome too: see [CONTRIBUTING.md](CONTRIBUTING.md).
