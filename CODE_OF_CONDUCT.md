# Code of Conduct

Stream → Shorts is a small open-source project. We want it to be a friendly place for everyone who uses it, reports a bug, translates a text or sends code, whatever their experience, background or identity.

This code of conduct is adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We pledge to make taking part in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be kind and patient, especially with newcomers and people writing in a second language.
- Respect different opinions and experiences; disagree about ideas, not people.
- Give and accept constructive feedback gracefully.
- Take responsibility for mistakes, apologise to those affected, and learn from them.
- Focus on what is best for the people who use the app.

## Unacceptable behaviour

- Insults, personal or political attacks, and trolling.
- Sexualised language or imagery, and unwelcome sexual attention.
- Public or private harassment.
- Publishing someone else's private information (address, e-mail, real name, recordings) without their explicit permission.
- Any other conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This code of conduct applies in all project spaces (issues, pull requests, discussions, reviews) and when someone officially represents the project elsewhere.

## Reporting

If someone's behaviour makes you uncomfortable, contact the maintainer, [@ANIR13](https://github.com/ANIR13), privately: use **Security → Report a vulnerability** on the repository (it creates a private report only the maintainer can see) and say that it is a conduct report. You can also use GitHub's own **Report content** option on any comment.

All reports are reviewed promptly and kept confidential. The person reporting will not suffer any consequences for a report made in good faith.

## Enforcement

The maintainer may, depending on how serious the behaviour is and whether it happened before:

1. **Correct:** a private message explaining what was wrong, and possibly a request for a public apology.
2. **Warn:** a warning with consequences if the behaviour continues.
3. **Ban temporarily:** no interaction with the project for a set time.
4. **Ban permanently:** for repeated or serious violations, including harassment.

Comments, commits, code, issues and other contributions that break this code of conduct may be edited, hidden or removed.
